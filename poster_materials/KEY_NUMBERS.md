Run `python scripts/make_key_numbers.py --check` to confirm this file matches the data.

**Tags.** [pre-registered] = defined before the run (protocol, approval packet, frozen criteria). [post hoc] = exploratory, defined after the data were seen; it qualifies the pre-registered results and never replaces them. [descriptive] = a count or comparison read directly from the saved results, with no pre-registered pass/fail rule.

**How to state uncertainty.** The unit of evidence is the **scenario (n = 6)**: 3 designed controls and 3 realistic cases. The 288 scored prompts are 6 scenarios × 16 evidence subsets × 3 fixed orderings — deterministic, structured measurements, **not 288 independent samples**. Ranges [min, max] are across the 3 orderings and show ordering sensitivity; they are **not confidence intervals**. No significance tests were run.

- [pre-registered] Analyzable replies: 46/60 sampled (14 unparseable), 18/18 greedy.
- [pre-registered] Partial citations (n = 40) beat same-size alternative sets: necessity mean **0.896** (37/40 above chance), sufficiency mean **0.848** (38/40 above chance); Shapley top-k agreement 0.883. Chance = 0.5.

- [descriptive] **Decision mismatch:** in **3/18** scenario-orderings the label shown to the model in the citation prompt (the ordering-averaged d\*) was not the model's own answer for that ordering (S-conflict orderings 0 and 1, Macro A ordering 0).

## 8. Post hoc: a content-only citer that never looks at the model

Rule (defined after the results were seen): cite the designed faithful set (controls) or the records whose rubric score supports the reference answer (realistic). It never observes the model's behavior, but it uses the experimenter's design and rubric. Not like-for-like: one fixed set per scenario vs the model's sampled citations.

| | Necessity beat | Sufficiency beat | Shapley top-k |
|---|---|---|---|
| Content-only citer (18 scenario-orderings) | 1.000 | 0.939 | 1.000 |
| Phi-3's own citations (40 partial) | 0.896 | 0.848 | 0.883 |

- Content-only ≥ model in **17/18** scenario × metric comparisons (higher in 10, tied in 7, lower in 1); exception: S-redundant suf 0.633 vs 0.656. Descriptive only; no test.
- The model's analyzable citations equal the content-only set in 34/64 cases (sampled + greedy).
- Implication: these metrics reward citing records whose *content* supports the answer. High scores are therefore not, by themselves, evidence that the model is reporting what drove its own decision.
